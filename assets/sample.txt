qqcode sample text
==================

This file is something to show with qqcode-show and to read back with qqcode.
It is short, so that a first try does not take long, and it is text, so that
what arrives can be looked at: if this sentence is on the other machine as it
is here, the screen, the camera and the two programs get along.

A file goes from one machine to the other through nothing but light. The
machine that has it puts it on a screen, as QR codes on a terminal or as a
matrix of coloured tiles on a web page. The machine that wants it points a
camera at that screen. There is no cable between the two and no network, and
the machine with the file never learns whether anybody is looking.

It is not only text that can be sent this way. To the programs a file is a
row of bytes, and these lines are bytes like any others. The ones below are
not plain ASCII, and each of their characters takes three bytes:

    這個檔案是用來測試的。把它顯示在螢幕上，用相機拍下來，
    另一台機器就能把它一個位元組都不差地讀回去。

Every printable character of ASCII, in order:

     !"#$%&'()*+,-./0123456789:;<=>?
    @ABCDEFGHIJKLMNOPQRSTUVWXYZ[\]^_
    `abcdefghijklmnopqrstuvwxyz{|}~

Characters that are easily taken for one another, which matters to a program
that reads text off a picture and not at all to one that reads codes:

    0 O o    1 l I |    5 S s    8 B    2 Z z    rn m    vv w    , . ; :
